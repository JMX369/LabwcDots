# Keybinds

| Keys | Action |
|:-|:-|
|<kbd>super</kbd> + <kbd>T</kbd>| Alacritty
|<kbd>Super</kbd> + <kbd>B</kbd> | Browser
|<kbd>Super</kbd> + <kbd>E</kbd> | Pcmanfm
|<kbd>Super</kbd> + <kbd>R</kbd> | Reconfigure
|<kbd>Super</kbd> + <kbd>X</kbd> | Session Panel
|<kbd>Super</kbd> + <kbd>D</kbd> | Show desktop
|<kbd>super</kbd> + <kbd>F</kbd>| Maximize switcher
|<kbd>super</kbd> + <kbd>Space</kbd>| show launcher
|<kbd>F11</kbd>| Fullscreen switcher
|<kbd>Print</kbd>| Screenshot
|<kbd>Alt</kbd> + <kbd>Tab</kbd>| Next Window
|<kbd>Alt</kbd> + <kbd>F4</kbd>| Kill Focused Window
|<kbd>super</kbd> + <kbd>Q</kbd>| Kill Focused Window
|<kbd>super</kbd> + <kbd>Shift</kbd> + <kbd>1-5</kbd>| Charge the Focused Windows to Other Workspace
|<kbd>super</kbd> + <kbd>1-5</kbd>| Charge the Workspace
